Shortest paths on a road network

Definitions, the two search rules, and a proof that A* returns the same route as Dijkstra

1. Model

Let \(G=(V,E)\) be a graph whose vertices are junctions and whose edges are road segments. Every vertex \(v\) has a position \(p(v)\in\mathbb{R}^2\) in kilometres. For a segment \((u,v)\in E\), let \(d(u,v)=\lVert p(u)-p(v)\rVert_2\) be its length and \(s(u,v)\in\{30,60,80\}\) its speed in km/h for local, arterial and highway roads. Live traffic multiplies travel time by a factor \(\tau(u,v)\ge 1\). The cost of a segment is its travel time in minutes:

\[ w(u,v)=\frac{60\,d(u,v)}{s(u,v)}\,\tau(u,v) \tag{1} \]

The cost of a path \(P=(v_0,v_1,\dots,v_k)\) is the sum of its segment costs, and \(\delta(s,v)\) denotes the least cost of any path from \(s\) to \(v\):

\[ c(P)=\sum_{i=1}^{k} w(v_{i-1},v_i), \qquad \delta(s,v)=\min_{P:\,s\to v} c(P) \tag{2} \]

Because \(w\ge 0\) on every segment, a cheapest path never repeats a vertex.

2. Dijkstra's algorithm

Maintain a tentative cost \(g(v)\) for every vertex, with \(g(s)=0\) and \(g(v)=\infty\) otherwise. Repeatedly remove the open vertex with the smallest tentative cost and relax its outgoing segments:

\[ u=\operatorname*{arg\,min}_{v\in Q} g(v), \qquad g(v)\leftarrow \min\bigl\{\,g(v),\; g(u)+w(u,v)\,\bigr\} \tag{3} \]

Invariant. When \(u\) is removed from \(Q\), \(g(u)=\delta(s,u)\).

This holds because any other path to \(u\) must leave the settled set through a vertex whose tentative cost is at least \(g(u)\), and all remaining segments cost \(\ge 0\). After settling every vertex with \(\delta(s,v)\le r\), the search has covered the set of vertices reachable within travel time \(r\). On the map this is an isochrone that grows in all directions, including away from the destination.

3. A* search

A* uses the same loop but orders the queue by an estimate of the total cost through \(v\):

\[ f(v)=g(v)+h(v) \tag{4} \]

The heuristic \(h(v)\) estimates the remaining time to the target \(t\). Here it is the straight-line distance driven at the fastest speed any road allows, \(v_{\max}=80\) km/h:

\[ h(v)=\frac{60\,\lVert p(v)-p(t)\rVert_2}{v_{\max}} \tag{5} \]

For the result to be optimal, \(h\) must be admissible and, for each vertex to be settled only once, consistent:

\[ h(v)\le \delta(v,t) \quad\text{(admissible)}, \qquad h(u)\le w(u,v)+h(v) \quad\text{(consistent)} \tag{6} \]

Lemma 1. The heuristic (5) is consistent, and \(h(t)=0\).

Proof. By the triangle inequality, \(\lVert p(u)-p(t)\rVert \le \lVert p(u)-p(v)\rVert + \lVert p(v)-p(t)\rVert\). Multiplying by \(60/v_{\max}\) gives

\[ h(u)\;\le\;\frac{60\,d(u,v)}{v_{\max}}+h(v)\;\le\;\frac{60\,d(u,v)}{s(u,v)}\,\tau(u,v)+h(v)\;=\;w(u,v)+h(v), \]

since \(s(u,v)\le v_{\max}\) and \(\tau(u,v)\ge 1\). \(\blacksquare\)

Consistency implies admissibility, because summing the inequality along a cheapest path from \(v\) to \(t\) gives \(h(v)\le\delta(v,t)+h(t)=\delta(v,t)\).

Theorem 1. With a consistent heuristic, A* returns a path of cost \(\delta(s,t)\), the same as Dijkstra, and settles each vertex at most once.

Proof. Define reduced costs

\[ w'(u,v)=w(u,v)+h(v)-h(u)\;\ge\;0. \tag{7} \]

A* on \(w\) is exactly Dijkstra on \(w'\), because \(f(v)=g(v)+h(v)\) equals the reduced cost \(g'(v)\) of reaching \(v\), up to the constant \(h(s)\). For any path \(P\) from \(s\) to \(t\) the extra terms telescope:

\[ c'(P)=\sum_{i=1}^{k}\bigl(w(v_{i-1},v_i)+h(v_i)-h(v_{i-1})\bigr)=c(P)+h(t)-h(s)=c(P)-h(s). \tag{8} \]

Every path is shifted by the same constant, so the cheapest path under \(w'\) is the cheapest path under \(w\). Dijkstra's invariant on non-negative weights then gives the claim. \(\blacksquare\)

4. Which vertices are searched

Let \(C^{*}=\delta(s,t)\). Dijkstra settles every vertex with \(\delta(s,v)\le C^{*}\). A* settles only vertices whose estimate does not exceed the optimum, up to ties:

\[ \mathcal{S}_{\text{A*}}\subseteq\{\,v:\ \delta(s,v)+h(v)\le C^{*}\,\}\;\subseteq\;\{\,v:\ \delta(s,v)\le C^{*}\,\}=\mathcal{S}_{\text{Dijkstra}} \tag{9} \]

The second inclusion uses \(h\ge 0\). The better \(h\) approximates \(\delta(v,t)\), the smaller the first set. With \(h\equiv 0\) the two algorithms coincide.

Algorithm 1. A* search. Dijkstra is the case \(h\equiv 0\).
input: graph G, source s, target t
1   g(v) ← ∞ for all v;  g(s) ← 0;  Q ← { s with key h(s) }
2   while Q is not empty
3       u ← vertex in Q with the smallest key f
4       if u = t then return the path ending at t, following parent pointers
5       mark u settled
6       for each segment (u, v) with v not settled
7           if g(u) + w(u,v) < g(v) then
8               g(v) ← g(u) + w(u,v);  parent(v) ← u
9               insert or update v in Q with key g(v) + h(v)
10  return no route

5. Complexity

With a binary heap, each segment causes at most one queue update and each update costs \(O(\log|V|)\), so both algorithms run in

\[ O\bigl((|V|+|E|)\log|V|\bigr) \tag{10} \]

in the worst case, using \(O(|V|)\) memory. A Fibonacci heap improves the bound to \(O(|E|+|V|\log|V|)\). The worst case does not change with \(h\); only the searched region (9) does. When traffic changes, \(\tau\) changes, the weights (1) change, and the search is simply run again on the new weights.
